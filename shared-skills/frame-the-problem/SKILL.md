# Frame the Problem

Identify the affected person, observed failure and consequence. Trace a recent real case and consider the strongest competing explanation. Ask the user only for evidence or a decision you cannot obtain from the available sources.

Recommend the problem to pursue and explain what would change your mind. If evidence is insufficient, name the cheapest observation that would distinguish the alternatives.
