# Prove the Gap

State the desired outcome and the capability the proposal assumes is missing. Exercise the strongest existing path on a representative case. Check whether the remaining gap matters to an actual user and who would own a new solution.

Recommend using the existing path, piloting, building, declining, or gathering a specific missing fact. Give the evidence and the smallest next step. Stop when further research is unlikely to change the decision.
