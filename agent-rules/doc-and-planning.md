# Doc Authoring & Planning Artifacts

For a design doc, RFC, spec, runbook, or playbook, use the relevant authoring workflow and follow `~/dotfiles/claude/doc-style/rubric.md`.

Use Lavish when a real choice, visual comparison, diagram, or structured feedback will make review easier. Use concise chat or Markdown for a small plan with no visual decision surface. Open a Lavish artifact with `open-lavish <file>` and use `lavish-axi-safe` for later polling or shutdown.
