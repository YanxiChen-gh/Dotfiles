# Codex session control

Use the desktop session tools available in this chat. Resolve the saved project and host from current metadata. A saved SSH project retains its host when launched with the local project environment.

Give a new chat its requirements, constraints and accessible evidence. Keep returned host and chat IDs, pending creation IDs and wait cursors. After an uncertain create or send, check its status before retrying. Distinguish a launch receipt, an idle chat and completion of the requested work.

Start or message only the chats the user requested. Report a missing capability or inaccessible target directly. Diagnose connections only when requested.
