# Organizer run scope

Use `begin`'s `scope` and `affectedChats` as authoritative. A scheduled/full request can upgrade a pending event reservation before acquisition. Treat a missing legacy scope as full. Use one per-chat classifier, PR-association rule and closure guide in both scopes.

For `events`, normally inspect only the affected eligible chats and their actual tracked-work PRs or directly necessary evidence. Prioritize new, unmanaged candidates. Resolve each host/thread through native tools, read its actual request and latest meaningful exchanges, establish creation/scope eligibility, then classify, verify placement and save its ledger/audit promptly. Raw lifecycle/status flags never determine a section. A repository URL or contextual dependency does not authorize unrelated PR refreshes.

Do not put complete histories, other managed chats, quiet PR refreshes or unrelated SSH enrollment ahead of event placement. Extract only relevant ledger entries and eligibility/override metadata for inspection; preserve the remaining state when saving. If a source is internal, old backlog, invisible, unknown or unavailable, record an exclusion or coverage deferral with evidence; never invent a chat or declare unseen work Done. Use only minimal host/sidebar metadata needed to resolve affected identities and manual overrides.

Event passes update affected entries and scoped audit only. Do not advance complete host-discovery checkpoints or the ledger's full-sweep success marker; explicitly record event scope and coverage.

For `full`, handle affected eligible chats first, then perform the canonical full discovery/reconciliation and tracked-PR refresh, including quiet chats. Advance complete checkpoints only after verified coverage. Full-scope launchers perform automatic enrollment after launching/binding the worker, or after recording a deferred full request, so provisioning does not delay affected-chat placement.

Events arriving after acquisition remain for a later pass. A scheduled request during an active pass remains full-sweep intent. Never preempt a writer. Preserve unknown launches, failures and pending metadata for safe retry; restore unfinished scope without immediate failure-only retry loops.
